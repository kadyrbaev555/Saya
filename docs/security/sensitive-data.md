# Чувствительные данные

Текущий MVP допускает демонстрационные ответы. Survey хранит минимальный boolean input и явные consent/version. Assessment хранит provenance, input и результат в собственной БД; AI stateless. Через Rabbit передаются только UUID/version, через Centrifugo — id/status/version. JWT содержит только subject/role/технические claims. Логи не включают пароли, токены, ответы или результаты.

Refresh hashes хранятся отдельно от клиента; web долгоживущий токен только HttpOnly cookie, native только системное secure storage. Public responses и метрики не раскрывают персональные идентификаторы в labels. DB volumes не опубликованы на host. Production требует отдельной политики удаления, retention, резервного копирования/шифрования и TLS/service authentication — это ещё не завершённые эксплуатационные функции.

Новый локальный проект saya-v13 использует независимые секреты; старый saya остановлен, его volume и защищённая конфигурация сохранены. Старый local admin secret попал в диагностический вывод, поэтому повторно использовать его не следует. Изменение пароля/ролей старой БД требует отдельного согласования, новый проект от них не зависит.
