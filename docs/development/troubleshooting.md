# troubleshooting

Если compile: version go1.26.0 does not match go1.25.1, задайте GOROOT=/usr/local/go только для команды. Docker socket в sandbox требует разрешённого доступа. Ошибка загрузки Docker image — проверить сеть Docker Desktop; не удалять volumes. Ошибка dev-init file exists защищает существующие секреты.
